# VibeCheck

Public backup of the VibeCheck Base44 web app (social games: daily challenges, rooms, quizzes, leaderboards).

## Stack
Vite + React, Base44 backend, Tailwind + shadcn/ui.

## Setup
```bash
npm install
npm run dev
```

Source snapshot only — no production secrets or user data.
